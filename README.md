# hoot-install

The install kit for [Hoot](https://github.com/CLDMV/hoot), a self-hosted speech service. These scripts take a host from nothing to a running Hoot container; everything after that happens in Hoot's own web UI. GitHub Pages serves this repo.

```bash
curl -fsSL https://cldmv.github.io/hoot-install/install.sh | sh        # Linux, macOS
```

```powershell
irm https://cldmv.github.io/hoot-install/install.ps1 | iex             # Windows (PowerShell)
```

```bash
npx @cldmv/hoot-install                                                # anywhere Node is installed (not published to npm yet)
```

The repo holds no Hoot code and no credentials: the bootstrap scripts, the generic installer they download (`v<version>/installer.tgz`, Node built-ins only), Hoot's public install manifest and checksums. The scripts are generated by `rummage installer pack`; don't edit them by hand.

## Verifying a script before running it

Each version lives in its own folder and is never rewritten. Download the script and the checksums, check, read, then run:

```bash
curl -fsSLO https://cldmv.github.io/hoot-install/v0.1.0/install.sh
curl -fsSLO https://cldmv.github.io/hoot-install/v0.1.0/SHA256SUMS
sha256sum -c --ignore-missing SHA256SUMS
less install.sh
sh install.sh
```

The script pins the installer archive and the portable Node it may download by SHA-256, and stops before running anything that doesn't match.
